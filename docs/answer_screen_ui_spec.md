# 診断回答画面 UI仕様（v2：キャラ会話形式）

## 更新履歴
- v1：1問ずつ画面遷移・横スライダー・進捗リビール画像のみの仕様（前セッション）
- v2（本版）：ゲーム会話風の演出を追加。各設問をキャラが直接問いかける形式に変更

---

## 1. 全体コンセプト

RPGの会話シーンのように、キャラクターが1問ずつ話しかけてくる形式で29問に回答する。回答手段（横スライダー）自体はv1から変更しない。「診断を受けている」感覚を薄め、「ゲームをプレイしている」感覚に寄せることが目的。

## 2. 質問キャラクター

- **29問すべてに、異なる固定キャラを1体ずつ割当**（重複なし）
- 割当ロジック：各設問の因子（開放性・誠実性・外向性・調和性・繊細さ)と相性の良いキャラを機械的に選定。ただし該当因子のスコアが特別高いことを条件とはしない
- レア度構成：N10体・R8体・SR5体・SSR6体（UR以上は不使用。N〜SSRの範囲で必要数を十分にまかなえたため）
- キャラと設問の対応、セリフ本文は `game_dialogue_29.json` を参照
- 設問順は既存仕様通りランダム化される。キャラは各設問に紐づいて固定のため、キャラの登場順も結果的にランダムになる
- **セリフは質問一文のみ**で構成する。キャラが自分の傾向を語る自己言及・決めつけ表現は含めない（誘導を避けるため）
- 一人称・語尾は`factor_comments_53`で確立された各キャラの口調に準拠する

## 3. 画面レイアウト

```
┌─────────────────────────────┐
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░ │ ← 進捗バー（画面上部の細い帯）
├─────────────────────────────┤
│                               │
│         [背景イラスト]         │ ← 共通1枚の固定背景
│                               │
│      [キャラ立ち絵]            │ ← 設問ごとに差し替え
│                               │
│  ┌───────────────────────┐   │
│  │ セリフ（吹き出し）        │   │ ← ダイアログボックス
│  └───────────────────────┘   │
│                               │
│ あてはまらない ●─●─●─●─●─●─● あてはまる │ ← 横スライダー（7段階）
│                               │
│ [わからない]         [スキップ] │ ← バー下、左右固定
└─────────────────────────────┘
```

### 背景
- **共通1枚の固定背景**を全29問で使用（キャラ絵のみ差し替え）
- イラスト方針・生成プロンプトは別途検討（次タスク）

### キャラ立ち絵
- 設問ごとに`game_dialogue_29.json`の`speaker.imageKey`に対応する絵に差し替え
- 表示位置は背景内の一定エリア（下部中央〜やや左右いずれかで固定、既存ガチャ演出のキャラ表示位置に準拠）

### セリフ（ダイアログボックス）
- RPGの会話ウィンドウ風のUI（半透明〜不透明の吹き出し／ウィンドウ）
- 表示テキストは`game_dialogue_29.json`の`dialogueLine`をそのまま使用
- タップで次へ進む一般的なゲーム会話UIとは異なり、本UIでは**スライダー操作＝回答＝次の設問へ進む**動作を兼ねる（会話送り操作は不要）

## 4. 進捗表示

- **配置：画面上部の細い帯**
- 内容：横長1枚のイラスト（29個の汎用アイテム/小モンスター、結果キャラとは無関係でネタバレ防止）を、回答するごとに1/29ずつクリップ表示で見せる範囲を広げる演出（v1から変更なし）
- 新規アセットは1枚で済む

## 5. 回答操作（横スライダー）

- 7段階評価。数字は表示せず、両端に「あてはまらない」「あてはまる」ラベルのみ
- 7段階分の位置にスナップ。タップ/ドラッグで選択→自動で次の設問へ
- v1から変更なし

## 6. わからない／スキップ

- バー下、左下に「わからない」、右下に「スキップ」を固定配置
- 7段階と視覚的に区切って配置し、意図して選ぶ操作にする
- v1から変更なし
- 特殊トリガー（スキップ率/わからない率50%以上）との関係：UI上で隠さず同列表示する設計のため、意図的に連打するユーザーが出ることを見込んだ上での配置（v1から変更なし）

## 7. 戻る操作

- 可能。前の設問に戻って回答変更でき、進捗リビール画像も該当位置まで巻き戻る
- 戻った際、当該設問に紐づくキャラ・セリフも再表示される
- v1から変更なし

## 9. キャラ立ち絵・ダイアログボックス（確定仕様）

### キャラ立ち絵
- 表示位置：背景の空けてあるスペースに合わせて、画面中央のやや下寄り
- 表示範囲：**腰から上（バストアップ〜上半身）を基本**とする（全身表示にすると29体分すべてで背景との合成位置調整が必要になるため、統一する）
- サイズ：画面幅の50〜65%程度を目安に、背景に対して圧迫感が出ない大きさ
- 横位置：中央固定（背景のテーブル配置と干渉しないよう、左右にはずらさない）

### ダイアログボックス
- 吹き出し形式ではなく、RPGの会話ウィンドウ風の帯（名前欄＋テキスト欄）
- 画面下寄りに固定表示。キャラ立ち絵の下部に少し重なる形で配置
- 左上に小さくキャラ名（アイコンは省略、テキストのみ）
- 半透明〜不透明の紺〜藍色の背景に金の縁取り（結果ページのトーンと統一）

### 画面内の縦の並び（上から）
1. 進捗バー（細い帯）
2. 背景＋キャラ立ち絵
3. ダイアログボックス（キャラ立ち絵に少し重ねる）
4. 横スライダー
5. わからない／スキップ
