- `higher`｜私より確かめるのだな。自分がいるかどうかから始める私が言うのも妙だが、程々に
- `lower `｜私より確かめずにいられるのだな。自分を疑わずに済む者は、朝の支度が短くてよい


## OR帯

### 全てを内包する根源神「アルス」
スコア: 開放性5 / 誠実性4 / 外向性1 / 調和性6 / 繊細さ7

- `lower `｜わたしより落ち着いている方ですね。思いつきで形にするわたしより、確かなものが残ります

- `higher`｜わたしより人と関わる方ですね。話す相手がいないわたしには、それが眩しく見えます
- `lower `｜―

**調和性**

- `higher`｜わたしより人のために動く方ですね。放っておけないわたしより、さらに深く関わります
- `lower `｜わたしより自分の分を残せる方ですね。放っておけないわたしより、無理がありません

**繊細さ**
- `same `｜あれで良かったのかと、後から考え続ける方ですね。わたしもです。今も考えております
- `higher`｜―
